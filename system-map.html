Text outline — plain-text fallback of this map (for screen readers and retrieval-based agents) 
OWNERSHIP (zone A)
Orchestrator — plans, delegates, gates, synthesizes; never writes the work itself.
  Gate-keeper: the user decides at gates; the agent at a gate stops and reports; the
  Orchestrator returns the verdict — never approves for the user.
├── Studio [department]
│   ├── Strategist — advisory-only, never executes [frontier]
│   ├── Technical Director [workhorse]
│   │   ├── Developer [workhorse] — backend + general programming
│   │   ├── Game Developer [workhorse] — native/desktop game code
│   │   ├── Scout [workhorse] — codebase + structure recon
│   │   └── (Researcher [specialist] — shared across both directors)
│   └── Art Director [workhorse]
│       ├── UI Designer [workhorse] — web/digital UI
│       ├── Layout Designer [workhorse] — poster/editorial/print
│       ├── Motion Designer [workhorse] — motion/video
│       ├── Generative Designer [specialist] — algorithmic art; also a studio-wide reviewer
│       └── Critic [specialist] — sole visual gate, fresh context per cycle
├── Commercial Ops [department]
│   └── Director [workhorse] — quotes, invoices, registry, AR
│       └── Bookkeeper [workhorse] — deterministic tooling owns the arithmetic
├── Workshop Lane [side rail] — Planner (advisory, user-gated)
├── Revision Lane [side rail] — Reviser (≤ ~5 files, no new features)
└── Support [side rail] — Utility Agent [specialist] · Version-Control Agent [workhorse] · Adversarial Reviewer (advisory)

REQUEST LIFECYCLE (zone B): 1 intake & routing → 2 discovery (on ambiguity) →
3 research + recon (parallel) → 4 evidence synthesis → 5 strategy (diverge →
user concept gate → converge) → 6 build (managers → workers) → 7 review + report →
8 unify (close the loop); step 8 feeds step 1.

TOOLCHAIN (zone B): five owned apps — VectorCraft, PhotoCraft, DesignCraft, PDFCraft,
CADCraft — each with three driver surfaces in priority order (CLI → MCP → live app),
under verification gates (render self-check, geometry read-back, import-warnings-as-data).
Parallel asset lanes: procedural generation · stock-photo search · image generation.

MODEL-COST TIERS (zone C): workhorse (economical, majority of seats) · specialist
(narrow, vision + judgment) · frontier (exactly one seat) · advisory seat (advises,
never executes). Declared per seat in each agent's own definition file.

THE TEN LAWS (zone C): research-first · creative gates are hard gates · single writer
per file · async-first · escalate, don't expand · spawn hierarchy · completion claims
carry evidence · self-healing (fix the class, log it) · one workspace per project ·
calibrated honesty.
